# Русская вселенная — прототип MVP

Офлайн-прототип цифровой экосистемы «Русская вселенная»: одна страница, ванильный JavaScript,
никакого бэкенда и внешних запросов. Все данные хранятся в `localStorage` браузера.

**Живая версия:** https://mabus46.github.io/russian-universe/

**Как запустить локально:** скачайте репозиторий и откройте `index.html` в браузере (двойной клик) —
всё работает без интернета. Подойдёт и любой статический сервер: `python3 -m http.server 8000`.

## 3. Модель данных и «проверяемость»

* Состояние хранится в `localStorage` под ключом `ru:state:v1`. Если хранилище недоступно,
  прототип работает в памяти и честно пишет об этом в подвале меню.
* Каждая значимая операция (урок, покупка, залог, голос, помощь) добавляет запись в журнал:
  `{ id, ts, type, label, lad, meta, prevHash, hash }`, где `hash = FNV-1a(prev | type | label | lad | ts | meta)`.
* Кнопка «Проверить целостность» пересчитывает цепочку: подмена записи ломает связь и видна сразу.
* Это иллюстрация механики, а не криптография: хеши считает браузер, подписей и распределённого
  реестра в прототипе нет (см. п. 6).
* Паспорт продукта и лента помощи используют ту же идею: шаг → хеш → следующий шаг.

## 4. Этика и приватность (по §0 и §13 ТЗ)

* **Уровни за вклад, а не за происхождение.** Очки вклада нельзя купить, передать или получить «по статусу».
* **Один человек — один голос.** Вес голоса в сообществе не зависит от уровня и баланса.
* **Объяснимость ИИ.** У каждого ответа ассистента есть «почему так» и источники; ассистент отвечает
  «не знаю» вместо домысливания и не выступает от лица антагониста «Тень».
* **Нет слежки.** Нет геолокации, чтения переписки, скрытого профилирования. Киберщит показывает
  категории отфильтрованного контента, а не поведение ребёнка.
* **Несовершеннолетние.** Маркировка 6+/12+/16+/18+, детский профиль скрывает экономику
  и самоуправление, доступ к ним — только по коду родителя (в демо `1234`) и на 10 минут.
* **Право на данные.** Экспорт, импорт и удаление — в разделе «Этика и данные», без запросов в поддержку.
* **Без политики и «свои/чужие».** Тексты говорят о делах, местах и продуктах.
* **Медицина и финансы.** Здоровье — привычки, а не диагностика; «Лад» — бонусная единица, а не валюта
  и не финансовый инструмент; реальных платежей нет.

## 5. Технические решения

* Ванильный JS (ES5-совместимый синтаксис), без сборки и зависимостей; DOM собирается через хелпер `h()`.
* Canvas 2D — для спарклайнов показателей; SVG — для карты, дерева и иконок.
* Адаптив: 320 px, 375 px, планшет, десктоп, широкие экраны; на мобильных — таббар и выдвижное меню,
  шиты открываются снизу.
* Доступность: семантические кнопки, `aria-label`, `aria-current`, видимый фокус, `prefers-reduced-motion`.
* Шрифты подключены локально через `@font-face` с раздельными кириллическим и латинским диапазонами.

## 6. Что демонстрационное, а что отложено

**Работает по-настоящему (в рамках браузера):** навигация, состояние профиля, уровни и вклад, корзина и заказ,
уроки и олимпиада, голосования, брони и залоги, помощи, журнал операций с проверкой, экспорт/импорт/удаление,
родительский код, адаптивная вёрстка.

**Заглушки, честно помеченные в интерфейсе:**

* ответы ИИ-ассистента — выбор из локальной базы знаний по ключевым словам, без языковой модели;
* показатели слобод — сгенерированные демо-числа, а не данные датчиков;
* плеер Студии «Русь» — прогресс-бар-заглушка, видео и 3D не загружаются (офлайн-требование);
* доставка, оплата, модерация обращений — имитация с записью в журнал;
* хеш-цепочка — FNV-1a в браузере, а не промышленный реестр.

**Вне прототипа (следующие этапы):** интеграции с ЕСИА/Госуслугами, платёжный провайдер и юридически
значимые договоры, VR/AR-движок и медиатека, промышленный распределённый реестр, серверная модерация,
аналитика и A/B-тесты.

## 7. Проверочный сценарий (5 минут)

1. Онбординг: имя → режим → ассистент. Появляется главная с уровнем «Росток».
2. `#/assistant`: спросить «Как начисляется токен «Лад»?», раскрыть «почему так» и источники.
3. `#/slobody/voronezh` → «Открыть продукты слободы» → паспорт продукта → «Проверить цепочку».
4. `#/market`: добавить два товара → «Оформить заказ» → «Подтвердить». Баланс уменьшился, заказ в истории.
5. `#/tree`: «Проверить целостность» — цепочка сходится; в журнале видны заказ и уроки.
6. `#/lesson/eco-7-l1`: ответить на вопрос → «Завершить урок» — переход на следующий, +5 вклада и +10 Ладов.
7. `#/kopa`: проголосовать, увидеть пересчёт полосы «за / против / воздержался».
8. `#/wishes`: забронировать перфоратор (залог 20 Л), затем «Вернуть и получить залог».
9. `#/shield`: включить «Строгий режим» — потребуется код родителя `1234`.
10. `#/ethics`: «Экспорт всех данных» → JSON; затем «Удалить все данные» → профиль сбрасывается.

## 8. Как обновлять сайт

1. Измените файлы локально и проверьте прототип в браузере (`Ctrl+F5`).
2. На GitHub: **Add file → Upload files** → выберите изменённые файлы → **Commit changes**.
   Папки загружать не нужно — все файлы лежат в корне.
3. Подождите 1–2 минуты: GitHub Pages пересобирается автоматически при каждом коммите.
4. Откройте сайт с `Ctrl+F5`, иначе браузер покажет старую версию из кеша.

Ветка публикации: `main`, источник — `/ (root)`. Настраивается в **Settings → Pages**.
